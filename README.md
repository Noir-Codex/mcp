# AI-Агент управления складом с базой данных

## Описание

Система управления складом с AI-агентом, который понимает естественный язык и работает с товарами, хранящимися в базе данных SQLite. Решение автоматизирует рутинные операции управления складом, экономя время менеджеров и снижая риск ошибок.

## Бизнес-ценность

### Проблема
- Менеджеры склада тратят много времени на рутинные операции: проверку остатков, создание заявок, поиск товаров
- Высокий риск человеческих ошибок при ручном вводе данных
- Сложность быстрого получения актуальной информации о состоянии склада

### Решение
- **Автоматизация операций** - агент выполняет запросы на естественном языке
- **Экономия времени** - до 20-30 минут в день на рутинные операции
- **Снижение ошибок** - автоматическая валидация и обработка данных
- **Быстрый доступ** - мгновенное получение информации о товарах и заявках

### Целевая аудитория
- Менеджеры складов и логистики
- Складские работники
- Руководители отделов снабжения
- Компании с активным складским учетом

## Возможности

### Управление товарами
- ✅ **Создание товаров** - "добавь товар яблоки 100 кг"
- ✅ **Удаление товаров** - "удали товар яблоки"
- ✅ **Просмотр всех товаров** - "покажи все товары"
- ✅ **Поиск товаров** - "найди картошку"
- ✅ **Проверка количества** - "сколько картошки на складе"
- ✅ **Обновление запасов** - автоматически при операциях

### Управление заявками
- ✅ **Создание заявок** - "сделай заявку на пополнение картошка 50 кг"
- ✅ **Просмотр статуса** - "статус заявки REQ-20251206-001"
- ✅ **Обновление статуса** - одобрение/отклонение заявок
- ✅ **Список заявок** - с фильтрацией по статусу и товару

## База данных

**Файл:** `warehouse.db`

**Таблицы:**
- `products` - все товары
- `reorder_requests` - заявки на пополнение

**Автоматическая миграция:** При первом запуске создаются начальные товары (морковь, картофель, капуста, лук, помидоры).

## Инструменты агента (10 шт)

1. `search_products` - поиск товаров по названию
2. `get_inventory_status` - статус запасов товара
3. `update_inventory` - обновление количества
4. `create_reorder_request` - создание заявки
5. `get_reorder_status` - статус заявки
6. `update_reorder_status` - обновление статуса заявки
7. `list_reorder_requests` - список заявок
8. `create_product` - создание товара
9. `delete_product` - удаление товара
10. `list_products` - список всех товаров

## Бизнес-кейсы использования

### Кейс 1: Ежедневная проверка остатков
**Задача:** Менеджеру нужно проверить остатки 20 товаров каждый день  
**Традиционно:** 15-20 минут на поиск в системе и запись данных  
**С агентом:** "покажи все товары с низким остатком" - 10 секунд  
**Экономия:** ~15 минут в день = 5 часов в месяц

### Кейс 2: Создание заявок на пополнение
**Задача:** При низком остатке нужно создать заявку на пополнение  
**Традиционно:** 3-5 минут на заполнение формы заявки  
**С агентом:** "сделай заявку на пополнение картошки 100 кг" - 5 секунд  
**Экономия:** ~3 минуты на заявку

### Кейс 3: Поиск товара по названию
**Задача:** Найти товар, зная только название (не SKU)  
**Традиционно:** Поиск по базе, уточнение SKU, проверка остатков - 2-3 минуты  
**С агентом:** "найди картошку и покажи остаток" - 5 секунд  
**Экономия:** ~2 минуты на поиск

## Деплой в Cloud.ru Evolution AI Agents

> 📖 **Подробная инструкция по деплою:** См. [DEPLOYMENT.md](DEPLOYMENT.md)

### Подготовка к деплою

1. **Проверьте наличие всех файлов:**
   - `tools.json` - описание всех MCP инструментов
   - `requirements.txt` - зависимости проекта
   - `.env` или `env.example` - переменные окружения
   - `mcp_server/` - код MCP-сервера
   - `agent/` - код AI-агента

2. **Настройте переменные окружения:**
   ```bash
   EVOLUTION_API_KEY=ваш_api_ключ
   EVOLUTION_API_URL=https://foundation-models.api.cloud.ru/v1
   EVOLUTION_MODEL=Qwen/Qwen3-235B-A22B-Instruct-2507
   MCP_SERVER_URL=http://localhost:8000
   ```

### Инструкция по деплою

1. **Загрузите проект на платформу Cloud.ru Evolution AI Agents:**
   - Войдите в панель управления Evolution AI Agents
   - Создайте новый агент или выберите существующий
   - Загрузите файлы проекта

2. **Настройте MCP-сервер:**
   - Убедитесь, что `tools.json` находится в корне проекта
   - Проверьте, что все инструменты описаны в `tools.json`
   - Настройте переменные окружения на платформе

3. **Запустите компоненты:**
   - MCP-сервер должен быть доступен по указанному URL
   - Агент должен быть настроен на использование Evolution Foundation Models API
   - База данных SQLite будет создана автоматически при первом запуске

4. **Проверьте работу:**
   - Протестируйте основные функции через интерфейс платформы
   - Убедитесь, что агент корректно вызывает MCP инструменты
   - Проверьте формат ответов A2A
